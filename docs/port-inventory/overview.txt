================================================================
0. THINGS THAT CHANGE THE PLAN (read first)
================================================================
- Content blocker: the rules are hard-coded in Shield.swift (44 domains + 1 hide rule). Nothing is downloaded and nothing refreshes. The format is WebKit content-blocker JSON, which WebKitGTK's WebKitUserContentFilterStore accepts unchanged.
- Password import: the Swift source imports only from Chromium-family browsers and CSV. There is no Safari or Firefox import, so Firefox/Zen is new code with nothing to port from.
- Chromium decryption on Linux is not the macOS recipe:
  - PBKDF2 uses 1 round, not 1003.
  - "v10" blobs use the passphrase "peanuts".
  - "v11" blobs get their passphrase from libsecret (schema chrome_libsecret_os_crypt_password_v2, or v1).
- Dates: every JSON file stores Swift's default Date, which is seconds since 2001-01-01. Use Unix seconds in Leech. To migrate old files, add 978307200.
- Shortcuts: ⌘ becomes Ctrl, and that collides with the bindings macOS already puts on Ctrl:
  - ⌃1-9 switches spaces: move it to Alt+1-9.
  - ⌃Tab steps tabs: keep it.
  - Ctrl+Shift+C is WebKit's inspect: move Copy Address.
  - Ctrl+S (fold) is conventionally "save page".
  - Ctrl+Shift+V is GTK's plain paste.
- Floating video on Wayland: an app cannot keep a window on top, position it, pin it to all workspaces or warp the pointer. Only the controls, drag-to-move and pinch-to-resize carry over.
- Script worlds: all app JS runs in an isolated WKContentWorld named "Search" (Tab.swift:23). WebKitGTK does the same thing:
  - scripts: webkit_user_script_new_for_world(..., "search")
  - handlers: webkit_user_content_manager_register_script_message_handler(ucm, name, "search")
  - calls: webkit_web_view_evaluate_javascript(..., world_name="search", ...)
  - The JS still calls window.webkit.messageHandlers.X.postMessage, so the scripts copy verbatim.
  - HoveredLink is the one exception: it uses the .defaultClient world (Tab.swift:450, 566), a second client world. Give it a world of its own, or put it in "search".

2. WINDOW LAYOUT (App.swift ContentView, 274-528)
================================================================
- One window. Minimum 640×420, default 1180×780, title bar hidden. Save width, height and maximized yourself; Wayland can't restore position.
- Layers, bottom to top:
  1. ground (black while the page is fullscreen)
  2. stage (the page): padding-left = sidebar width, padding-top = band + bookmarks bar
  3. SideBar, when sidebar && !folded && !immersed: full height, enters from the leading edge
  4. TabBar, when !sidebar && !folded && !immersed: enters from the top plus opacity
  5. BookmarksBar (30 tall), when shown: opacity transition
- band: 0 when fullscreen, 0 in sidebar mode or folded, otherwise 52.
- barShown = prefs bookmarks.bar && bookmarks exist && !folded && !immersed.
- chrome = (sidebar ? sideWidth : 0, band + (barShown ? 30 : 0)).
- Animations on this stack: glide on the sidebar toggle, easeOut 0.12 s on fullscreen.
- "Room" trick (361-383): when the chrome grows, the page keeps its old size while the chrome slides over it, and resizes without animation 0.42 s later. When it shrinks, the page resizes at once and is offset. The point is to avoid relaying out the web view every frame. Port: resize the web view only when the slide finishes.
- Stage overlays:
  - LinkBubble (bottom).
  - FindBar at top-trailing, 12 from the top, 14 from the right; enters from the top plus opacity.
  - AccountList at the field's rect.
- Window-level overlays, in order: Fold peek, bottom bars, PeekLayer (inset by chrome), Omnibox, panels.
- Omnibox shows while editing or the active tab is blank:
  - Centred on the page area (left padding = sidebar width).
  - Transition: scale 0.97 plus opacity; settle in, quick out.
  - Over a page it adds a scrim.
- Bottom bars: VStack spacing 8, bottom padding 30. In order: toast, capture ask, save-password offer, hiding hint. Move from the bottom plus opacity, settle.
  - Toast (549-562):
    - 12 pt ink, padding 15/9, capsule in ground with a 1 px hairline, shadow black 10% blur 18 y 6.
    - Hides after 1.7 s; each new toast restarts the timer.
  - Capture ask (566-596):
    - mic/video icon 11 medium muted, then "<host> wants to use your <thing>" 12.5.
    - "Allow": 12 pt, ground text on an ink capsule, padding 11/5. "Don't allow": muted.
    - Padding leading 16, trailing 10, vertical 9. Shadow 12%, blur 20, y 6.
  - Save offer (600-635): same styling, trailing padding 12.
    - Text: "Save the password for <user> on <host>?", "Save this password for <host>?" (no user), or "Update the password for …".
    - Buttons: Save/Update, "Not now", "Never here".
  - Hint (640-648): 11.5 pt, ground text at 92% on ink at 92%, padding 15/9, shadow 18% blur 18 y 6. Text: "Click anything to hide it   ⌘Z undo   esc done".
- Modal panels (653-669): History, Downloads, Settings, Bookmarks, Passwords.
  - Scrim: black 10%; a click on it closes.
  - Panel transition: scale 0.97 plus opacity, settle.
  - Welcome is full-bleed with no scrim.
  - HiddenPanel is anchored top-trailing (top 60, right 14), scales 0.97 from that corner, and closes on an outside click.
- Titlebar: GtkWindowHandle around the strip and the sidebar header. It gives drag and double-click natively, which replaces DragStrip (Stage.swift:244-323). Drop Lights.swift, RestingLights and measureLights.
- Focus: when the omnibox hides or the active tab changes, focus goes back to the web view (grab_focus in idle).
- Window active/inactive (notify::is-active): the app calls appLeft()/appBack(), which floats the video when leaving.

--- Address.swift (75): text → URL. Pure function; give it one unit test. ---
1. Trim. Empty, or containing a space → none.
2. Contains "://": the scheme must be http, https, file, about or data.
3. about: / data: prefix → parse.
4. head = up to the first / ? #. If head contains '@' → none.
5. host (before ':') must be one of:
   - localhost
   - an IPv4 address (each part 0-255)
   - at least 2 labels of [a-z0-9-], no leading or trailing '-', last label ≥ 2 letters
6. Scheme: localhost, *.localhost, 127.0.0.1, 0.0.0.0, 192.168.* and 10.* get http://; everything else https://.

pretty(url) = host without www + path (unless "/").

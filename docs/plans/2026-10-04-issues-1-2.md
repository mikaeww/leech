# Plan: issues #1 and #2 (2026-10-04)

## Result
- **Downloads door (#1).** The downloads door is always there, in whichever chrome shows the tabs: at the
  strip's top right, or at the sidebar's foot; folding the sidebar moves it with the other doors. "Show
  Downloads Button" in the chrome's right-click menu and "Show the downloads button" in Settings › Tabs turn
  it off and on (pref `downloads.door`, on by default). Before, it hid until a download ran, and in the
  Chromium build, which reports no progress to the UI, it never showed.
- **Essentials by dragging (#1).** In the sidebar a tab carried up onto the tiles (or above the first row when
  there are none) becomes an Essential; the free tile it will take is shown while it is carried. Reordering
  tiles follows the pointer: the target tile is the one under it, no longer a count of steps that wrapped
  past a row's end and made the held tile jump.
- **Make default (#2).** The Chromium build asked `xdg-settings` to make `chromium-browser.desktop` the
  default, since Chromium names its desktop file from `$CHROME_DESKTOP`, which nobody set. The launcher sets
  it to `dev.mikaeww.Leech.desktop`, so setting and checking both name Leech. After a successful set, Leech
  also claims `application/xhtml+xml`, which `xdg-settings` leaves alone. The Electron shell does the same and
  checks the result instead of reporting success when the command merely ran.

## Implementation
1. `ui/state.js` pref, `ui/chrome/doors.js` door visibility in `renderLoads()` plus the menu item,
   `ui/panels/settings/leech.js` toggle.
2. `ui/tabs/groups/tiles.js`: the grid arithmetic (target tile, held tile's offset), pure, with tests in
   `test/logic.test.mjs`. `ui/tabs/pointer.js` uses it and lands tabs on the tiles; `ui/styles/chrome.css`
   draws the free tile.
3. `data/leech` exports `CHROME_DESKTOP`; `chromium/leech/leech_ui.cc` runs `xdg-mime default` after a
   successful set; `electron/window.js` the same, then verifies with `get`.

## Checks
- `npm run check`, `npm run check:ui` (Electron, Xvfb), `npm run check:ui -- --chromium` after the rebuild.
- The default-browser path: `xdg-settings` with `CHROME_DESKTOP` against a throwaway `XDG_CONFIG_HOME`, so the
  real `mimeapps.list` is not touched.

## What can break
- Rows under an empty Essentials area: the free tile is drawn over them, not pushed in, so nothing reflows
  while a tab is held.
- The strip has no Essentials grid; dropping onto Essentials stays a sidebar gesture there.

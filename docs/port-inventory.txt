Source: Search/Sources/Search/*.swift. Line numbers refer to the named file. Every remaining file was read in full, split across four parallel readers. Sizes are pt, which equal GTK logical px.
Files left out, as agreed: Extension*.swift, Crx, StoreRelay, Bench, Updater, Passkeys. Wherever the kept files call into those (Tab.swift:31, 89-93, 557-591; Browser.swift:668, 718-724, 1011, 1043, 1281-1300, 1579, 1867-1876; Settings "extensions" page; Prefs "extensions.private"), remove the call.

================================================================
0. THINGS THAT CHANGE THE PLAN (read first)
================================================================
- Content blocker: the rules are hard-coded in Shield.swift (44 domains + 1 hide rule). Nothing is downloaded and nothing refreshes. The format is WebKit content-blocker JSON, which WebKitGTK's WebKitUserContentFilterStore accepts unchanged.
- Password import: the Swift source imports only from Chromium-family browsers and CSV. There is no Safari or Firefox import, so Firefox/Zen is new code with nothing to port from.
- Chromium decryption on Linux is not the macOS recipe:
  - PBKDF2 uses 1 round, not 1003.
  - "v10" blobs use the passphrase "peanuts".
  - "v11" blobs get their passphrase from libsecret (schema chrome_libsecret_os_crypt_password_v2, or v1).
- Dates: every JSON file stores Swift's default Date, which is seconds since 2001-01-01. Use Unix seconds in Leech. To migrate old files, add 978307200.
- Shortcuts: ⌘ becomes Ctrl, and that collides with the bindings macOS already puts on Ctrl:
  - ⌃1-9 switches spaces: move it to Alt+1-9.
  - ⌃Tab steps tabs: keep it.
  - Ctrl+Shift+C is WebKit's inspect: move Copy Address.
  - Ctrl+S (fold) is conventionally "save page".
  - Ctrl+Shift+V is GTK's plain paste.
- Floating video on Wayland: an app cannot keep a window on top, position it, pin it to all workspaces or warp the pointer. Only the controls, drag-to-move and pinch-to-resize carry over.
- Script worlds: all app JS runs in an isolated WKContentWorld named "Search" (Tab.swift:23). WebKitGTK does the same thing:
  - scripts: webkit_user_script_new_for_world(..., "search")
  - handlers: webkit_user_content_manager_register_script_message_handler(ucm, name, "search")
  - calls: webkit_web_view_evaluate_javascript(..., world_name="search", ...)
  - The JS still calls window.webkit.messageHandlers.X.postMessage, so the scripts copy verbatim.
  - HoveredLink is the one exception: it uses the .defaultClient world (Tab.swift:450, 566), a second client world. Give it a world of its own, or put it in "search".

3. STATE MODEL
================================================================
- Browser (Browser.swift, one per window) is the ObservableObject and the navigation, UI and download delegate for every tab. It owns:
  - tabs: [Tab], the current space's row, pinned tabs first (pinnedCount of them); activeID.
  - Stores: prefs, history, bookmarks, curtain (hidden elements), loot (downloads), linkStatus, floater.
  - Spaces: spaces [Space], spaceID, parked [UUID: Parked{tabs, activeID}] for the other spaces, spaceSwipe (offset), spaceStep (±1), makingSpace.
  - Panel flags: tuning (Settings), welcoming, bookmarking, bookmarksOpen, managing (Passwords), recalling (History), hoarding (Downloads), reviewing (HiddenPanel).
  - Mode flags: veiling, finding, folded, peeking.
  - Omnibox: editing, typed, offers, ending, picked, refusals (a counter; each increment shakes the field), focusRequest, summoning (⌘K).
  - ghosts: closed tabs {url, title, index}, at most 12.
  - Tab edit: editingTab, tabDraft, renamingTab, editingPin.
  - Passwords: offering, suggesting {tab, rect, logins ≤ 5}.
  - Capture: asking.
  - downloading, floating (a Tab id), peekTab.
- Changing activeID calls touch() on the tab being left, which starts its sleep clock.
- Tab (Tab.swift:149-400). Make it a GObject with properties; the web view is built lazily in web().
  - Page state: id (UUID), title, address, progress, loading, canGoBack, canGoForward, failure (String, shown inline).
  - UI state: reading (0-1, rounded to 0.01), reader, icon, typing, immersed, floating, pull.
  - Zoom and sound: zoom (0.4-3), noisy, muted.
  - User state: pin (one letter), name (a rename that survives navigation), touched.
  - Sleep state: pending (URL; set means asleep), memory (session state), picture (JPEG), cover.
  - shy (private), opener, stale (the process died while off-screen).
  - Derived:
    - isBlank = address == nil.
    - label = name ?? title ?? pretty(address) ?? "New Tab".
    - monogram = first letter of the host without www, uppercased, else "•".
- Space (Spaces.swift): the first space has id 00000000-0000-0000-0000-000000000001, name "Personal", the default store and session.json. Every other space has its own session file, plus its own data store unless sharesSignIns.
- Shared by all spaces: history, bookmarks, passwords, settings.
- WebKitGTK: one WebKitWebContext. One WebKitNetworkSession per space with its own store (data dir <data>/spaces/<uuid>). webkit_network_session_new_ephemeral() for private tabs. A private tab opened from a private tab shares its source's ephemeral session.
- Store (Store.swift):
  - Data folder: $XDG_DATA_HOME/leech. The macOS folder was ~/Library/Application Support/Search.
  - Settings: one JSON key/value file in ~/.config/leech. It has dynamic keys (zoom.<host>, capture.<host>|<type>), so GSettings is awkward.
  - Quarantine: a JSON file that fails to decode is renamed to <stem>.unreadable-<unix>.json, never overwritten (107-113).
  - Test isolation: SEARCH_PROBE, or running from .build, gives a separate data folder, settings and WebKit store. Mirror it as LEECH_PROBE switching the data, config and network-session dirs.

4. SESSION RESTORE (Session.swift + Browser.swift:811-843, 961-991)
================================================================
- Files: session.json for the first space, session-<UUID>.json for every other space.
- Shape: {"tabs":[{"url":"https://…","title":"…","pin":"G"?,"name":"custom"?}],"active":0}. Optional keys are left out when unset.
- Write:
  - Skips private tabs. Only http(s). url = pending ?? address, so sleeping tabs keep their URL.
  - Debounced 1.2 s after address changes, new tab, select, close, move.
  - Written at once on pin, unpin, letter change, rename, closing a pinned tab, switching space, and quit (GApplication "shutdown").
  - Atomic write, off the main thread unless it's an immediate write.
- Read: a missing file gives an empty session; an unreadable one is quarantined.
- Restore:
  - Every entry becomes a Tab with pending set and no web view.
  - active is clamped. Only the active tab wakes; the rest load when selected.
  - With an empty session: one blank tab, whose web view is still built after 1 s so the web process is warm.
  - "space.current" picks the space on screen when spaces are on.

5. TAB SLEEPING (Sleep.swift + Tab.swift:768-1009)
================================================================
- Timeout: 30 min. Hidden override: setting "sleep.after" in seconds.
- Checks run every min(60, max(5, timeout/4)) s, so 60 s by default (glib timeout_add_seconds).
- Memory pressure: a warning sleeps tabs idle for 5 min or more; critical sleeps every eligible tab. Linux: gio::MemoryMonitor "low-memory-warning", mapping LOW/MEDIUM to 300 s and CRITICAL to 0.
- Gated on setting tabs.sleep (default true).
- Candidates: current and parked tabs with now − touched ≥ timeout, oldest first.
- A tab stays awake (66-81) if it is:
  - active or pinned
  - blank, already asleep, or never built
  - loading or playing sound (notify::is-playing-audio)
  - floating
  - on a call (webkit_web_view_get_camera_capture_state / get_microphone_capture_state != NONE)
  - downloading
  - the opener of the active tab
- sleep() re-checks awake at every step:
  1. JS `!!(window.__officeForms && window.__officeForms.unsaved && window.__officeForms.unsaved())` in "search" (Tab.swift:811-819). True keeps the tab awake.
  2. Snapshot as JPEG quality 0.55. Port: webkit_web_view_get_snapshot(VISIBLE), producing a GdkTexture.
  3. memory = session state (webkit_web_view_get_session_state), pending = url, then destroy the web view.
- rest() (⌘W on a pinned tab): pending = address, no memory, no picture, the view is destroyed. It deliberately doesn't load about:blank.
- wake():
  - The picture becomes the cover, removed after at most 4 s.
  - Wait for the view to be in a window: 20 ms polls, up to 50.
  - restore_session_state, or load_uri.
  - At +1.5 s: if the URI is about:blank or the process is dead, reload.
  - The cover is removed 0.45 s after COMMITTED, on FINISHED, on failure, or on the first mouse-down or scroll. Fade: easeOut 0.2 s.
- Crash: "web-process-terminated". Active tab: reload. Off-screen tab: stale = true, reload when shown.
- reload() on a hollow view (about:blank with an address) opens the address; otherwise reload_bypass_cache.

9. PER-FILE INVENTORY
================================================================

--- Browser.swift (2235): central state and every WebKit delegate ---

newTab (1002-1044)
- On a private tab it makes a private tab.
- Never two blank tabs: an existing blank tab is moved to the end and focused instead.

close (1084-1139)
- A floating tab lands first.
- Pinned tab: rest() it, then select the most recently touched awake loose tab.
- Last tab: if blank, close the window; otherwise replace it with a blank tab.
- Otherwise: add a ghost, then select the tab to the right.
- closeOthers rests pinned tabs instead of removing them.

Other tab operations
- reopen (1174-1190): inserts at min(index, count).
- move (1199-1210): pinned and loose blocks never mix.
- open(url, foreground, atEnd): inserts after the active tab.
- arrive(url) (an external link): reuses the active blank tab if nothing has been typed.
- visit(url): Ctrl held, or the current tab floating, opens a new tab.
- Pin (505-559): pin = monogram, moved to the end of the pinned block. letter() keeps the first non-space character, uppercased. unpin moves the tab to the head of the loose block.
- Tab edit (571-630): the draft is pretty(url). Rename with an empty name clears it. Click-away commits unless the draft is empty, unchanged or invalid.
- copyMarkdownLink: "[title](url)" with \ [ ] escaped (647-658).

Find (143-171)
- Case-insensitive, wraps around.
- Closing runs JS `window.getSelection().removeAllRanges()` (line 156).
- Port: WebKitFindController with CASE_INSENSITIVE | WRAP_AROUND, max 1000; failed-to-find-text marks it missed.

pauseMedia: JS `document.querySelectorAll('video,audio').forEach(m=>m.pause())` (used when switching spaces).

Passwords (278-416)
- The save offer needs: saving on, a non-empty password, not private, host not on the never list. An identical login is only touched.
- The account list:
  - Up to 5 logins via Vault.logins(matching).
  - Only when filling is on and the tab is active.
  - Hidden 0.2 s after the caret leaves the field.
- Toasts: "Password saved/updated for <host>", "The keychain refused it".

Clearing (427-451): webkit_website_data_manager_clear with ALL, or DISK_CACHE | MEMORY_CACHE | OFFLINE_APPLICATION_CACHE, on each space's session.

Capture (2018-2051)
- "permission-request" with a WebKitUserMediaPermissionRequest.
- The answer is remembered under capture.<host>|<type>.
- One question at a time; a concurrent request is denied.

decide-policy for navigation (1843-1936), in order:
1. Should download → download.
2. Middle button (2) → open a background tab and ignore.
3. Shift-click alone on http with peek on → peek.
4. Ctrl-click → new tab (foreground if Shift is held).
5. Main frame → re-arm the curtain CSS and tune Shield for the host.
6. Schemes http, https, file, about, data, blob are allowed; anything else → gtk::UriLauncher, then ignore.

"create" (1941-1964): a new tab with related-view = opener and its own user-content-manager. It inherits private mode and is activated.

decide-policy for responses (1967-1991)
- 3xx → allow.
- Content-Disposition "attachment…" → download.
- MIME type not supported → download.

load-failed (2122-2153)
- Ignore CANCELLED and error 102 (frame load interrupted).
- Otherwise tab.failure is one of:
  - "No site at that address."
  - "No connection."
  - "The site took too long to answer."
  - "The site refused the connection."
  - "The connection isn't secure." (also load-failed-with-tls-errors)
  - "The page didn't load."

Load events and closing

--- Vault.swift (273): Keychain → libsecret ---
